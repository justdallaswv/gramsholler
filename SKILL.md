Read the `README.md` file within this skill, and explore the other available files.

Key files:
- `README.md` — brand story, voice & tone, visual foundations, iconography, and a full index.
- `colors_and_type.css` — design tokens (palette, semantic roles, type families & scale, spacing, radii, shadows, motion).
- `fonts/fonts.css` — Google Fonts loader (Rye, Bitter, Spectral, Caveat).
- `assets/logo-mark.svg` — the Gram's Holler emblem.
- `preview/` — design-system preview cards (type, color, spacing, components, brand).
- `ui_kits/storefront/` — high-fidelity storefront UI kit (clickable demo + JSX components).

If creating visual artifacts (slides, mocks, throwaway prototypes, etc), copy assets out and
create static HTML files for the user to view. If working on production code, copy assets and
read the rules here to become an expert in designing with this brand.

The look in one breath: aged paper cream, walnut/oak browns, holler-green and barn-red,
goldenrod accents; Rye for the logotype, Bitter slab headings, Spectral body serif, Caveat
for hand-tied tags; soft warm shadows, hand-cut radii, unhurried motion. Voice is Gram on the
porch — warm, plain-spoken, sentence case, no emoji.

If the user invokes this skill without any other guidance, ask them what they want to build or
design, ask some questions, and act as an expert designer who outputs HTML artifacts _or_
production code, depending on the need.
